# Workshop 42

Applied AI tools from Ottawa, built by [Josh Boyer](https://joshboyer.ca).

## What we build

**[guardrails](https://ws42.ca/guardrails)** stops AI coding agents from padding, weakening or bypassing your tests, docs and architecture. It ships as one CLI, one MCP server and one config file per project, and works with Claude Code, Codex, Gemini and Cursor.

    npm i -D @ws42ca/guardrails

[![npm](https://img.shields.io/npm/v/@ws42ca/guardrails)](https://www.npmjs.com/package/@ws42ca/guardrails)

**[Workshop 42 Build](https://build.ws42.ca)** is an AI website builder for small businesses. Tell it about your business, preview the site, then publish.
